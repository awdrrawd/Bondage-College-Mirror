repo//grep — 在瀏覽器裡直接讀取 GitHub 倉庫全文，像 F12 一樣，但對準整個 repo
或
貼好網址後按「載入倉庫檔案清單」，或直接選本機資料夾，兩者都會自動把文字檔內容載進瀏覽器記憶體，搜尋時不用等網路。
這個工具會：
1. 貼上 GitHub 網址，或直接「選擇本機資料夾」（瀏覽器只會跳出一次授權視窗，不用分開填 owner / repo / branch）
2. 載入後自動把所有文字檔內容讀進瀏覽器記憶體，關掉分頁就釋放；本機資料夾模式完全不連網路，速度取決於你的硬碟而不是網速
3. 沒有搜尋關鍵字時，左側以「資料夾樹狀收合」瀏覽；一輸入關鍵字，會依「命中檔案的上一層資料夾」分組並可收合，重複的翻譯檔不會洗版
4. 內容搜尋在背景載入還沒跑完時也能用，符合的檔案會邊讀邊冒出來，不用等全部讀完
5. 圖片/字型/音訊等二進位檔只列出名稱，GitHub 模式會附下載連結，本機模式可直接用「下載」按鈕另存
選一個檔案來看內容
（或先用左側清單 / 上方搜尋列找檔案）

  






  資料來源：GitHub REST API + raw.githubusercontent.com（只讀，不會寫入你的倉庫）
